# ProductCatalog

ProductCatalog is a full-stack Product Management System developed using
ASP.NET Core Web API, React, Entity Framework Core, and SQL Server.

## Technologies Used

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- Dependency Injection

### Frontend
- React
- JavaScript
- HTML
- CSS
- Vite

## Features

- Add new products
- View all products
- Update existing products
- Delete products
- Product validation
- REST API integration
- React frontend
- SQL Server database

## Architecture

```text
React Frontend
      ↓
ASP.NET Core Web API
      ↓
Business Logic Layer (BLL)
      ↓
Data Access Layer (DAL)
      ↓
SQL Server
